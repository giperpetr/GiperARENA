# ArenaHUB - Project Brief

## 🎯 Проект: ArenaHUB - Remote-Controlled Gaming Platform

**Дата создания:** 26 октября 2025  
**Статус:** В разработке (Phase 1)  
**Целевая дата запуска:** Q3 2026

---

## 📋 Краткое описание

ArenaHUB - это революционная платформа, которая соединяет физические арены с роботизированными устройствами (роботы, дроны, краулеры) с онлайн-игроками по всему миру. Пользователи могут управлять реальными устройствами в реальном времени, участвовать в турнирах, делать ставки и зарабатывать криптовалюту.

---

## 🎮 Ключевые возможности

### Основной функционал
- **Управление в реальном времени** - WebRTC с задержкой <100ms
- **Конкурентные игры** - Турниры с реальными призами
- **Система ставок** - Ставки на игры и турниры
- **Криптовалюта** - Заработок токенов GAC/PAC
- **NFT маркетплейс** - Торговля устройствами арен и достижениями
- **DAO управление** - Решения сообщества

### Технические особенности
- **WebRTC стриминг** - Управление роботами через браузер
- **Blockchain интеграция** - Solana smart contracts
- **Real-time коммуникация** - Socket.io + WebRTC
- **Масштабируемая архитектура** - Microservices на Docker

## 💰 Токеномика

### GAC (Government Arena Coin)
- **Назначение:** Управление и стейкинг
- **Общее количество:** 100,000,000 токенов
- **Стейкинг тиры:** Bronze (1K), Silver (10K), Gold (50K), Platinum (100K)
- **Дефляционная модель** - сжигание токенов

### PAC (Play Arena Coin)
- **Назначение:** Утилитарный токен для игр
- **Контролируемая инфляция** - 5% APY (убывающая)
- **Сжигание** - 10% при транзакциях
- **Использование** - Взносы за игры, награды

## 🔒 Безопасность и соответствие

### Техническая безопасность
- **JWT токены** - 15min access + 30 дней refresh
- **Row Level Security** - PostgreSQL RLS
- **Rate limiting** - 10 req/sec per IP
- **HTTPS везде** - Let's Encrypt SSL

### Регуляторное соответствие
- **KYC верификация** - Для ставок
- **Ответственная игра** - Лимиты ставок
- **GDPR** - Защита данных пользователей
